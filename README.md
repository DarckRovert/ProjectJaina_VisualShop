# WowPeruVisualShop — Catálogo Visual de WoW Perú

Tienda de cosméticos del Reino Andino. Permite adquirir y equipar alas, auras y títulos personalizados.

## Compatibilidad

- WoW 3.3.5a (Build 12340) | Lua 5.1 puro
- **Script de Servidor:** `59_SpellVisualCatalog.lua` (Eluna / TrinityCore / AzerothCore)

## Rangos de IDs Reservados

| Tipo | Rango |
|---|---|
| Alas (Modelos) | Spells `943001–943018` |
| Títulos Custom | Spells `940001–940049` |
| Auras Combinadas | Spells `941001–941999` |
| Auras de Forma | Spells `942001–942999` |
